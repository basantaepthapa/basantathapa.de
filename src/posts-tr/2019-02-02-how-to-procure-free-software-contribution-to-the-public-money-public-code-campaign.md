title: '„Wie man Freie Software beschafft“: Beitrag zur Kampagne „Public Money? Public Code!“'
---
Im Januar 2019 hat die [Free Software Foundation Europe](https://fsfe.org/) im Rahmen ihrer Kampagne [„Public Money? Public Code!“](https://publiccode.eu/) die Broschüre [„Public Money Public Code – Modernising Public Infrastructure with Free Software“](https://fsfe.org/news/2019/news-20190124-01.en.html) veröffentlicht. Darin steht ein kurzer Beitrag von mir mit einigen sehr grundsätzlichen Tipps, wie öffentliche Verwaltungen Freie Software beschaffen können.

Die Kampagne fordert, dass alle mit öffentlichen Mitteln entwickelte Software als Freie Software verfügbar gemacht wird. Dazu hat die FSFE eine „Expertenbroschüre“ über Einsatz, Wirkung und Vorteile Freier Software herausgegeben.

https://www.youtube.com/watch?v=iuVUzg6x2yo

Video der Kampagne „Public Money? Public Code!“

Da ich mich für ein anderes Projekt intensiv mit der Beschaffung von Software durch die öffentliche Hand in Deutschland beschäftigt hatte, war mein Beitrag ein leichtes Nebenprodukt. Zusätzlich habe ich meine Ergebnisse mit einigen Vertreterinnen und Vertretern von Interessengruppen für Freie und Open-Source-Software abgeglichen, um die bereits gesammelten Verwaltungsperspektiven zu ergänzen.

Ich kann alle Beiträge der Broschüre empfehlen. Neben leicht verdaulichen Grundlagen wie „10 Mythen über Freie Software“ gibt es einige Texte von echten Fachleuten, etwa zum wirtschaftlichen Nutzen und zu den Wettbewerbseffekten Freier Software, die auch für mich neue Einsichten enthielten.
